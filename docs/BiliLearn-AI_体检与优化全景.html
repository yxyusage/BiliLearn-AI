三、问题地图（9 个模块，共 70+ 项）
P0 核心体验硬伤 P1 功能正确性/完整性 P2 健壮性/工程化
笔记生成 P0×3
P0 扁平要点列表＝改写版字幕，无层级/例题详解/对比表，reduce 只合并不归纳
P1 时间戳丢失/编造、假 00:00:00；章节时间区间重叠；important 泛滥
P1 脑图 mindmap/graphTD 混用、自环重复 id、多断链，无校验
P1 英语"听力原文"模型复述产生听写幻觉（Sunden Fluff、extreme afiles）
P2 串行调用慢、无 json_mode、长 reduce 超窗风险
数学公式 P0×4
P0 只认 $ 分隔，不认 \( \) / \[ \] / 裸 LaTeX，跨行公式失配
P0 KaTeX 解析失败显示红色源码，无人类可读兜底
P0 识别结果是孤岛：不进正文/不进导出，且丢失帧对应
P0 关键帧与公式帧同名 frame_N 互相覆盖
P1 选项/答案/批改/错题/复盘全是纯文本，公式源码外露；PDF/Word 公式原样
AI 答疑 P0×5
P0 中文输入法组词回车误发送（未判 isComposing）
P0 流式中途报错覆盖已生成内容；HTTP 错误只见 "HTTP 400"
P0 流式中 Mermaid 未闭合反复渲染报错闪烁；代码围栏匹配过严
P0 上下文硬截断 6000 字，长笔记后半不可问
P1 150 字上限+强制画图；不持久化；无停止/复制/重试；列表表格不渲染
自测题 P1×5
P1 简答题主观批改价值低（可移除）
P1 单选答案字符串全等判定，模型答 "A" 即误判，应存选项索引
P1 题干选项/参考答案/反馈不渲染公式
P1 答题状态不落库，刷新可重做、错题重复入库
P2 输入截断 12000 字、时间戳不校验、归章随时间重叠失效
导出 P0×2
P0 导出＝扁平 points 换格式，无归纳层（用户感知"只是字幕"）
P0 PDF/Word：公式原样、**星号原样、脑图丢弃、图片路径依赖工作目录
P1 不含题目/错题/公式/复盘/脑图；Anki 仅英语生词；XMind 截断
P2 md 图片相对路径、删笔记留孤儿文件、window.open 失败无提示
播放器联动 P0×1
P0 跳转靠改 iframe src，每次整播放器重载、重新缓冲
P1 无法监听播放进度（当前知识点高亮、续播做不了）
P1 autoplay 可能被拦截；连点竞态；假 00:00:00 跳转误导
合集队列/转写 P1×3
P1 逐集串行；服务重启后 running 任务永久卡死，无恢复
P1 启动合集不带 Cookie；图谱 6章×3点+2万字截断，大课程后半丢失
P2 无取消/失败集重试；whisper 每次重载模型、无 VAD/进度；无唯一约束致重复笔记
复盘/复习 P1×2
P1 计划＝章节×6 条"复习章节X"，无知识点/链接/掌握度；重做即清空完成状态
P1 /review/plan 接口前端从未调用，导航无"今日复习"，功能半成品
P2 复盘时间戳不校验；错题无"已掌握"流转；非 SM-2
工程/部署 P2 为主
P0级隐患 Docker 未装 pyav/whisper，容器内关键帧/公式必坏
P2 katex 未在 package.json 声明（靠 mermaid 传递依赖）
P2 start.bat 见 dist 即跳过构建，更新代码后前端不刷新
P2 requirements 重复/缺 av、yt-dlp 下限旧；WAL 2.8MB 不 checkpoint
P2 Kimi 视觉模型名已过时；无线程池上限；v-html 面；版本号三处不一致；测试薄
建议的修复次序：第一批先做「确定性 bug + 高感知」——AI 答疑 5 项、播放器 postMessage、帧文件覆盖、公式渲染兜底与全链路渲染；第二批做「核心价值」——笔记 schema 升级（多级结构 + 二次归纳）与导出重写（题型可裁剪，简答先下线）；第三批做「健壮性」——任务持久化/恢复、Docker 依赖、复习闭环、合集质量。
