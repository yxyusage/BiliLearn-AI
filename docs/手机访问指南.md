# 手机访问 BiliLearn-AI 指南（局域网版）

让手机直接访问你电脑上运行的 BiliLearn-AI，无需公网服务器、无需安装任何 App。
原理：**手机和电脑接入同一个网络（比如手机热点、同一个 WiFi）时，它们就在同一个局域网内，手机浏览器可以直接访问电脑的 IP。**

---

## 适用场景

| 场景 | 是否可行 | 说明 |
|---|---|---|
| 电脑连手机热点 | ✅ 推荐 | 手机和电脑自动处于同一局域网，最方便 |
| 手机和电脑连同一个 WiFi | ✅ 可行 | 路由器下同一网段即可 |
| 两台设备在不同网络 | ❌ 不可行 | 需要内网穿透/公网部署（见文末） |

---

## 第一步：启动服务

双击项目根目录的 `start.bat`，看到 `[Start] Launching at http://localhost:8000` 表示启动成功。

> 服务默认监听 `0.0.0.0`（即所有网卡），**不需要修改任何配置**即可被手机访问。

## 第二步：查电脑 IP

1. 按 `Win + R`，输入 `cmd` 回车
2. 执行：`ipconfig`
3. 找到 **「无线局域网适配器 WLAN」** 的 **IPv4 地址**：

| 网络 | 常见 IP 段 | 示例 |
|---|---|---|
| Android 手机热点 | `192.168.43.x` | `192.168.43.7` |
| iPhone 热点 | `172.20.10.x` | `172.20.10.2` |
| 家庭路由器 WiFi | `192.168.1.x` / `192.168.0.x` | `192.168.1.5` |

## 第三步：放行防火墙（Windows 首次必做）

**方式 A（推荐）**：启动 `start.bat` 时，Windows 若弹出防火墙提示框，勾选「专用网络」和「公用网络」并点「允许访问」。

**方式 B**：没有弹窗或想手动放行，以**管理员身份**打开 cmd，执行：

```bat
netsh advfirewall firewall add rule name="BiliLearn-AI 8000" dir=in action=allow protocol=TCP localport=8000
```

想撤销时执行：

```bat
netsh advfirewall firewall delete rule name="BiliLearn-AI 8000"
```

## 第四步：手机访问

手机浏览器（推荐 Chrome / Edge / Safari）输入：

```
http://电脑IP:8000
```

例如 `http://192.168.43.7:8000`，即可看到完整的 BiliLearn-AI 界面。

手机版体验提示：
- 支持「**添加到主屏幕**」，会以独立窗口打开，像 App 一样使用（PWA）
- 已缓存的页面/笔记支持离线查看
- 做题时推荐先做选择题、判断题（点选即可），填空题/计算题需要打字，体验稍弱

---

## 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 手机打不开页面 | 防火墙没放行 8000 端口 | 执行第三步方式 B |
| 手机还是打不开 | 手机热点开了「AP 隔离」 | 热点设置里关闭「禁止设备间通信 / AP 隔离」 |
| 电脑突然断开热点后打不开 | 网络变了，IP 变了 | 重新 `ipconfig` 查新 IP；服务本身没停 |
| `start.bat` 启动报错 | 8000 端口被占用 | 关掉占用程序，或改端口后重启 |

---

## 进阶：不同网络也能访问（可选）

如果手机和电脑不在同一网络（如用 4G/5G 访问），需要内网穿透或公网部署：

- **Tailscale / ZeroTier**：组虚拟局域网，免费、稳定，最推荐
- **ngrok / frp**：内网穿透隧道，临时演示够用
- **公网服务器部署**：需注意 B 站字幕解析依赖 Cookie，且不要把 API Key 配置暴露到公网

> ⚠️ 安全提示：本工具把 API Key、B 站 Cookie 存在本地 SQLite（`backend/data/`），**只适合自己或信任的设备访问**，不要对陌生人开放端口。
