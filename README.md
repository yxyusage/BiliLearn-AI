# BiliLearn-AI

把 B 站学习视频变成可交互的结构化笔记、自测题和复习资料。输入视频或合集链接，自动完成字幕提取、AI 笔记生成、阶梯自测，所有内容绑定视频时间戳，点击直达对应片段。同时提供浏览器插件，在 B 站看视频时一键生成和浏览笔记。

---

## 它能做什么

| 场景 | 功能 |
|------|------|
| 十多小时的长视频，不知道从哪开始看 | **合集线路图**：AI 分析全合集，按知识模块分组，标注重难点，推荐学习起点 |
| 收藏夹里攒了一堆视频 | **收藏夹导入**：一键解析收藏夹，单视频和合集混合，选择性生成 |
| 看完就忘，笔记只是字幕流水账 | **教材精编笔记**：按定义→推导→例题→结论组织，分学科模板 |
| 复习时翻视频找重点太慢 | **合集复习资料**：多集笔记蒸馏重排为可打印 PDF，按知识点顺序编排 |
| 在 B 站看视频时想随时记笔记 | **浏览器插件**：侧边栏直接生成/浏览笔记，不用切换页面 |

## 快速开始（小白版）

### 第一步：安装环境

需要两个软件（如果已经装了可以跳过）：

1. **Python 3.10+**：去 [python.org](https://www.python.org/downloads/) 下载，安装时**一定要勾选「Add Python to PATH」**
2. **Node.js 18+**：去 [nodejs.org](https://nodejs.org/) 下载 LTS 版本安装

安装完成后，打开命令行输入 `python --version` 和 `node --version`，能看到版本号就说明装好了。

### 第二步：启动项目

```bash
# Windows 用户：双击项目根目录下的 start.bat
# macOS / Linux 用户：在终端运行 ./start.sh
```

脚本会自动完成：创建虚拟环境 → 安装依赖 → 构建前端 → 启动服务 → 打开浏览器。

- 第一次运行需要 2-5 分钟（下载依赖）
- 之后每次启动只需几秒钟
- 启动成功后浏览器会自动打开 `http://localhost:8000`

### 第三步：配置 API Key

1. 打开页面后，点右上角「设置」
2. 选择模型供应商（推荐 DeepSeek，性价比最高）
3. 填入 API Key，点「测试连接」确认可用
4. 保存设置

> API Key 仅保存在你电脑本地的 SQLite 数据库中，不会上传到任何地方。

### 第四步：生成第一篇笔记

1. 回到首页，粘贴一个 B 站视频链接（如 `https://www.bilibili.com/video/BV1xx411c7mD`）
2. 点「解析」，等待视频信息加载
3. 点「生成笔记」，等待 1-5 分钟（取决于视频长度）
4. 生成完成后自动跳转到笔记详情页

## 浏览器插件（推荐）

在 B 站看视频时，直接通过侧边栏插件生成和浏览笔记，不用切换页面。

### 安装步骤

1. 打开 Chrome 或 Edge 浏览器
2. 地址栏输入 `chrome://extensions/`（Edge 是 `edge://extensions/`）
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」
5. 选择项目下的 `extension/` 文件夹
6. 插件安装完成，工具栏会出现 📖 图标

### 使用方法

1. 确保后端服务已启动（`start.bat`）
2. 打开任意 B 站视频页面
3. 点工具栏的 📖 图标，右侧弹出侧边栏
4. 侧边栏功能：
   - **📝 笔记**：查看当前视频的笔记，或生成新笔记
   - **💬 答疑**：基于笔记内容向 AI 提问
   - **✏️ 题目**：生成自测题，检验学习效果
   - **📚 合集**：查看合集任务，点进合集可浏览每一集的笔记

### 注意事项

- Edge 用户需要在扩展详情页中，单独打开 `https://*.bilibili.com/*` 和 `http://127.0.0.1:8000/*` 的站点访问权限
- 插件和 Web 端共享同一份数据（本地 SQLite），在 Web 端生成的笔记在插件中也能看到

## 核心功能详解

### 笔记生成

- **教材精编结构**：定义→推导→例题→结论，拒绝字幕流水账
- **分学科模板**：通用/英语/数理/计算机/文科，各有专属笔记逻辑
- **全链路时间戳**：每个知识点绑定 `HH:MM:SS`，点击跳转视频对应片段
- **思维导图**：Mermaid 知识框架图
- **公式渲染**：LaTeX 公式自动渲染为人类可读形式

### 合集批量处理

1. 粘贴合集链接 → 解析 → 显示所有分集名称
2. 选择要生成的集数范围（如第 3 集到第 10 集）
3. 后台异步生成，默认 4 集并发，进度实时展示
4. 断网自动暂停，网络恢复后断点续传
5. 生成失败的笔记可手动重试，失败记录自动清理

### 合集线路图

- AI 分析全合集，按知识模块分组
- 标注重难点和推荐学习起点
- 适合不知道从哪集开始学的场景

### 合集复习资料

- 多集笔记蒸馏重排为一份可打印 PDF/Word
- **按知识点顺序编排**（不按视频顺序），避免重复
- 包含：目录页码、学习目标、易混点辨析、章节测试、答案篇、术语索引、速记卡
- 分学科模板：计算机贴代码、高数标重点公式、文科重论述

### 自测与复习

- **阶梯自测**：单选/判断/填空/计算/简答，难度分级
- **AI 答疑**：基于笔记上下文多轮对话
- **变式题**：一键生成换数字/换情境的新题
- **错题本**：错题自动记录，支持薄弱点复盘

### 导出

- 单篇笔记：Markdown / PDF / Word
- 合集复习资料：PDF / Word（带目录页码）
- 英语专项：Anki 卡片

### 核心工作流程

```
视频/合集链接
    │
    ▼
yt-dlp 解析视频信息 + 提取字幕
    │
    ├── 优先 B 站官方 CC 字幕
    └── 无字幕可选 faster-whisper 离线转写
    │
    ▼
字幕按 6000 字符分段（map-reduce）
    │
    ▼
逐段调用 AI 生成小节笔记（分学科模板）
    │
    ▼
全局汇总：章节结构 + 思维导图 + 考点
    │
    ▼
SQLite 存储
    │
    ▼
前端 / 插件展示：播放器联动 · 时间戳跳转 · 自测 · AI 答疑
```

### 字幕分块策略

不是固定截取一定数量的字幕发给 AI。后端按 **6000 字符** 将完整字幕切分为多个块，每块独立调用 AI 生成小节笔记（map），全部完成后再调用一次 AI 做全局汇总（reduce），合并重复知识点、生成章节结构和思维导图。

## 常见问题

**启动后浏览器没自动打开？**
手动访问 `http://localhost:8000`。

**解析成功但提示「未检测到官方字幕」？**
视频没有 CC 字幕。可在设置中开启「离线语音转写」（faster-whisper），支持中英文。

**长视频笔记不全？**
后端按 6000 字符分段、逐段生成后全局汇总。可在 `backend/app/config.py` 调小 `subtitle_chunk_chars`，或换大窗口模型（如 Kimi）。

**生成失败提示 API Key？**
到「设置」填写对应供应商的 Key，点「测试连接」确认。

**插件显示「无法获取视频信息」？**
刷新 B 站视频页面，确保页面完全加载后再打开插件。Edge 用户需检查扩展详情页的站点访问权限是否都打开了。

**数据存在哪里？**
所有笔记数据在 `backend/data/bililearn.db`（SQLite），每份笔记自动同步一份 Markdown 到 `backend/data/notes/`。

**手机连不上？**
确保手机和电脑在同一 WiFi，关闭电脑防火墙，用 `http://电脑IP:8000` 访问。
