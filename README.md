# BiliLearn-AI

把 B 站学习视频变成可交互的结构化笔记、自测题和复习资料。输入视频或合集链接，自动完成字幕提取、AI 笔记生成、阶梯自测、错题复盘，所有内容绑定视频时间戳，点击直达对应片段。

## 它解决什么问题

- 十多小时的长视频，不知道从哪开始看 → **合集线路图**：AI 分析全合集，按知识模块分组，标注重难点，推荐学习起点
- 收藏夹里攒了一堆视频，逐个解析太麻烦 → **收藏夹导入**：一键解析收藏夹，单视频和合集混合，选择性生成
- 看完就忘，笔记只是字幕流水账 → **教材精编笔记**：按定义→推导→例题→结论组织，分学科模板，带思维导图
- 复习时翻视频找重点太慢 → **合集复习资料**：多集笔记蒸馏重排为一份可打印 PDF，按知识点顺序编排，含目录页码、学习目标、易混点辨析、章节测试、答案篇、术语索引、速记卡

### 核心工作流程

```
视频/合集链接
    │
    ▼
yt-dlp 解析视频信息
    │
    ▼
字幕提取 ── 优先 B 站官方 CC字幕 ── 无字幕可选 faster-whisper 离线转写
    │
    ▼
字幕按 6000 字符分段（map-reduce）
    │
    ▼
逐段调用 AI 生成小节笔记 ── 分学科模板（通用/英语/数理/计算机/文科）
    │
    ▼
全局汇总：章节结构 + 思维导图 + 考点
    │
    ▼
SQLite 存储 + 自动同步 Markdown 文件
    │
    ▼
前端展示：播放器联动 · 时间戳跳转 · 阶梯自测 · AI 答疑
    │
    ├──► 错题本 → AI 薄弱复盘 → SM-2 复习计划
    ├──► 导出：Markdown / PDF / Word / Anki / XMind / CSV
    └──► 合集模式：线路图 · 收藏夹导入 · 复习资料汇总
```

### 字幕分块策略

不是固定截取一定数量的字幕发给 AI。后端按 **6000 字符** 将完整字幕切分为多个块，每块独立调用 AI 生成小节笔记（map），全部完成后再调用一次 AI 做全局汇总（reduce），合并重复知识点、生成章节结构和思维导图。长视频建议用大窗口模型（如 Kimi 32k）。

## 核心功能

### 笔记

- **教材精编结构**：定义→推导→例题→结论，拒绝字幕流水账
- **分学科模板**：通用/英语/数理/计算机/文科，各有专属笔记逻辑
- **全链路时间戳**：字幕、知识点、题目统一 `HH:MM:SS`，点击跳转视频片段
- **思维导图**：Mermaid 箭头式知识框架，节点内置时间戳
- **关键帧嵌入**：按章节提取视频截图，嵌入笔记和导出文档
- **公式识别**：视觉大模型识别板书/课件公式，自动转 LaTeX

### 自测与复习

- **阶梯自测**：题目嵌入各章节，AI 逐题批改讲解，错题自动入册
- **变式题**：一键生成 AI 变式（换数字/换情境），同一知识点多角度巩固
- **没懂换讲**：任意小节打点提问，AI 用更通俗的方式重讲
- **薄弱复盘**：基于错题分析薄弱点，给出复习优先级和对应视频片段
- **SM-2 动态复习**：四档自评（重来/困难/良好/简单），算法自动重排下次复习
- **学前诊断**：打开合集后续视频前，先抽测先修知识点，给出「可跳过/需复习」建议

### 合集与批量

- **合集批量队列**：后台异步逐集生成，进度实时展示，已完成集复用缓存
- **合集线路图**：AI 分析全合集，按知识模块分组，标注重难点，推荐学习起点，支持选择集数范围
- **收藏夹导入**：一键解析 B 站收藏夹，单视频和合集混合，选择性生成笔记
- **合集复习资料**：多集笔记蒸馏重排为可打印 PDF，按知识点顺序（不按视频顺序），含目录页码、学习目标、易混点辨析、章节测试（选择/填空/判断/计算/简答）、答案篇、术语索引、速记卡

### 英语专项

- 听力原文精校、生词提取（音标/释义/原句/时间戳）
- 连读/弱读/失去爆破等语音现象标注
- 智能听写填空（实词/短语/时态挖空），先听后填即时判分
- Anki 卡片导出

### 界面与导出

- 双布局播放器：左右分栏（分隔条可拖动）+ 视频置顶
- 三套主题配色（纸墨青/海盐蓝/秋日橙）× 深浅模式
- 侧边吸顶目录 + 阅读进度条
- 手机同局域网访问，PWA 支持添加到主屏幕
- 导出：Markdown / PDF / Word（含关键帧截图）/ XMind / Anki(.apkg) / CSV

## 快速开始

### 环境要求

- Python 3.10+（安装时勾选「Add Python to PATH」）
- Node.js 18+（LTS 版）

### 一键启动

```bash
# Windows：双击 start.bat
# macOS / Linux：./start.sh
```

脚本自动完成：创建虚拟环境 → 安装依赖 → 构建前端 → 启动服务 → 打开浏览器（http://localhost:8000）。第一次运行需 2-5 分钟，之后每次启动几秒。

### Docker

```bash
docker compose up -d --build
# 访问 http://localhost:8000
```

### 手动运行（开发）

```bash
# 终端 1：后端
python -m venv .venv
.venv\Scripts\activate          # Windows；mac/Linux 用 source .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload --port 8000

# 终端 2：前端
cd frontend
npm install
npm run dev                     # http://localhost:5173
```

### 启动后

1. 打开 http://localhost:8000，点右上角「设置」，填入 API Key（DeepSeek 性价比最高）
2. 回首页粘贴 B 站链接 → 解析 → 生成笔记

### 手机访问

电脑启动服务后，手机连同一 WiFi/热点，浏览器访问 `http://电脑IP:8000`。详细步骤见 [docs/手机访问指南.md](docs/手机访问指南.md)。

## 模型支持

| 供应商 | 获取 Key | 默认模型 | 特点 |
| --- | --- | --- | --- |
| DeepSeek | platform.deepseek.com | deepseek-chat | 性价比高，推荐 |
| Kimi | platform.moonshot.cn | kimi-k2.6 | 大窗口，适合长视频 |
| 通义千问 | 阿里云百炼 | qwen-plus | 国内生态，支持视觉模型 |

## 常见问题

**解析成功但提示「未检测到官方字幕」？**
视频没有 CC 字幕。可在设置中开启「离线语音转写」（faster-whisper），支持中英文。

**长视频笔记不全？**
后端按 6000 字符分段、逐段生成后全局汇总。可在 `backend/app/config.py` 调小 `subtitle_chunk_chars`，或换大窗口模型。

**生成失败提示 API Key？**
到「设置」填写对应供应商的 Key，点「测试连接」确认。

**数据存在哪里？**
所有笔记数据在 `backend/data/bililearn.db`（SQLite），每份笔记自动同步一份 Markdown 到 `backend/data/notes/`。
